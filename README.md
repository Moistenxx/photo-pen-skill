# photo-pen-skill

把照片做成「上半原图 + 下半 3×3 手绘涂鸦记忆网格」高级海报的 WorkBuddy skill。

## 效果
- 3:4 竖版，上下严格 1:1，各占 50%
- 上半：保留原始照片（轻微高级调色可选），不拉伸、不扭曲主体
- 下半：Naïve Hand-drawn Doodle 风格的 9 宫格「记忆清单」——压缩成 9 个最值得被记住的视觉单元，含手写标题与极小的 caption，像一页私人手帐 / 视觉日记 / collection sheet

## 使用
在 WorkBuddy 上传一张（或多张）照片，说下面任一句即可触发：
- 「把这些照片做成记忆海报」
- 「每张照片单独出一张手帐风 / collection sheet / 视觉日记海报」
- 「3:4 上下 1:1，上半原图下半涂鸦九宫格」

## 工作流（程序化拼合，保版式）
1. 原图裁切 / 缩放适配为 3:2（竖版照片默认智能横裁，偏重主体；也可等比留白）
2. ImageGen 基于原图语义生成 3:2 涂鸦层
3. PIL 把上下两半竖拼成 3:4
4. 每张照片独立输出，绝不拼多张

## 核心约束
- 一次生成整张 3:4 会让模型重画上半、比例失控 → 必须程序化拼合
- 下半做写实插画或完整描摹原图 → 违规，要压缩成 9 个图标单元
- 网格要 loose / organic，不是工整电脑表格
- 涂鸦要留白 + 纸纹颗粒感，不铺满

## 安装（用户级）
把本目录放到 `~/.workbuddy/skills/photo-pen-skill/`，WorkBuddy 重启即自动识别。
